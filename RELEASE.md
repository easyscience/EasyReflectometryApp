This is the graphical application of **EasyReflectometry**, for modelling and analysing reflectometry data.

**Installation:** download the archive for your operating system below, unzip it and run the installer inside. See the [installation instructions](https://github.com/EasyScience/EasyReflectometryApp/blob/master/INSTALLATION.md) for details, including the note for macOS.

**What's new:** see the [changelog](https://github.com/EasyScience/EasyReflectometryApp/blob/master/CHANGELOG.md).

**Documentation:** tutorials and user guides are at <https://easyscience.github.io/EasyReflectometryApp/>.

Experienced users who prefer scripting can use the underlying Python library, [easyreflectometry](https://github.com/easyscience/reflectometry-lib), directly.

Bug reports and feature requests are welcome in the [issue tracker](https://github.com/EasyScience/EasyReflectometryApp/issues).
