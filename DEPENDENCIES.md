# External Open Source Dependencies

EasyReflectometry is built on the following open source projects. If there are any issues with licensing, please contact us through the [issue tracker](https://github.com/easyScience/EasyReflectometryApp/issues).

## EasyScience libraries

* [easyreflectometry](https://github.com/easyscience/reflectometry-lib): BSD-3-Clause
* [easyscience](https://github.com/easyscience/core): [BSD-3-Clause](https://github.com/easyscience/core/blob/develop/LICENSE)
* [EasyApplication](https://github.com/easyscience/gui-components): BSD-3-Clause

## Reflectometry calculators

* [refnx](https://refnx.readthedocs.io/en/latest/): [BSD-3-Clause](https://github.com/refnx/refnx/blob/master/LICENSE)
* [refl1d](https://refl1d.readthedocs.io/en/latest/): [BSD](https://github.com/reflectometry/refl1d/blob/master/LICENSE.txt)
* [orsopy](https://github.com/reflectivity/orsopy) (ORSO file format): MIT

## Fitting and sampling

* [bumps](https://github.com/bumps/bumps): Public Domain, with component-specific licenses (including DREAM, the sampler used for Bayesian analysis); see [LICENSE.txt](https://github.com/bumps/bumps/blob/master/LICENSE.txt)
* [lmfit](https://lmfit.github.io/lmfit-py): [BSD-3-Clause](https://github.com/lmfit/lmfit-py/blob/master/LICENSE)
* [DFO-LS](https://github.com/numericalalgorithmsgroup/dfols): [GNU General Public License v3 or later (GPLv3+)](https://github.com/numericalalgorithmsgroup/dfols/blob/master/LICENSE.txt)
* [ArviZ](https://www.arviz.org): [Apache-2.0](https://github.com/arviz-devs/arviz/blob/main/LICENSE)

## Scientific Python

* [NumPy](https://numpy.org): BSD-3-Clause
* [SciPy](https://scipy.org): BSD-3-Clause
* [asteval](https://github.com/lmfit/asteval): MIT

## User interface and visualization

* [Qt for Python (PySide6)](https://doc.qt.io/qtforpython-6/): [LGPL-3.0 / GPL-2.0 / GPL-3.0](https://doc.qt.io/qtforpython-6/licenses.html)
* [Matplotlib](https://matplotlib.org): [Matplotlib License (PSF-based)](https://matplotlib.org/stable/project/license.html)
* [Plotly](https://plotly.com/python/): [MIT](https://github.com/plotly/plotly.py/blob/main/LICENSE.txt)
